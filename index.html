    🤖 How Agentic AI Works
    
          
    Live pipeline visualization — every phase of your code analysis
    
        
    
        
        
    
          
        
    

        
        
    
          
    
            
    ① Perceive
    
            
    Logs incoming code, token count, known error type from ML classifier
    
          
    
          
    
            
    ② Tool: AST
    
            
    Calls cpp_parser.build_ast() — recursive descent parser builds full parse tree
    
          
    
          
    
            
    ③ Reflect
    
            
    Reads ErrorNodes from AST + semantic issues; decides which strategy to apply
    
          
    
          
    
            
    ④ Action
    
            
    12 surgical strategies: missing `;`, typo fix, brace repair, type fix, if-parens, etc.
    
          
    
          
    
            
    ⑤ Verify
    
            
    Re-runs AST + SemanticAnalyzer; if ErrorNodes remain → another turn
    
          
    
          
    
            
    ⑥ Resolution
    
            
    Zero ErrorNodes → marks success, records healed code + reasoning trail
